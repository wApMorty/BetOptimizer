7. Le modèle apporte-t-il une information que le marché n'a pas ?

Comparer un modèle seul au marché est sévère : le marché contient déjà presque tout ce que le modèle sait. La question utile est ailleurs : en combinant les deux, fait-on mieux que le marché seul ? On mélange par moyenne géométrique des probabilités, p ∝ pmarché1−w · pmodèlew, avec un seul poids w réglé sur la validation 2024/25 (pas de 0,05) puis évalué sur le test. Si w vaut 0, le modèle n'apporte rien.

Limites

  • Le marché est ici l'adversaire : ce rapport mesure à quelle distance des cotes se situent les modèles, il ne promet aucun avantage.
  • Le meilleur réglage est en bordure de grille ; les écarts entre les meilleures configurations (quelques millièmes de log loss) sont du même ordre que le bruit de validation.
  • {{ rho_clamped }} prédictions du test ont dû voir leur ρ ramené dans le domaine où le facteur τ reste positif.
  • Les xG publiés n'existent que pour 2026/27 : le proxy ne peut être comparé qu'à ce petit échantillon.
  • Cotes de bookmakers étrangers ; la décote réelle chez Winamax ou Betclic se mesurera sur notre propre archive.
